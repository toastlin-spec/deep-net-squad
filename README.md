# 深海撈撈隊

撈網捕魚遊戲。拿著網子在海裡移動，看準魚群游進網框的時機，點一下把網子撈起來。撈到越多、連撈越久，彩票越多；集滿能量還會召喚黃金魚王。

**▶ 線上直接玩：<https://toastlin-spec.github.io/deep-net-squad/>**

整個遊戲就是一個 HTML 檔，不需要安裝，也不需要網路，用瀏覽器打開就能玩。電腦和手機（橫放）都可以玩。

## 怎麼玩

1. 打開上面的線上網址，或下載 `index.html` 用瀏覽器（Chrome、Edge、Safari 都可以）打開。
2. 選「關卡挑戰」或「街機模式」。
3. 移動網子圈住魚，點一下把網子撈起來。網框內的魚都有機會撈到，越靠近網框中心越容易成功。
4. 每撈一次網子要冷卻一下。撈到空網會讓「連撈」歸零，還會嚇跑附近的魚，所以不要亂撈。

### 操作

| 動作 | 電腦 | 手機 |
|---|---|---|
| 移動網子 | 移動滑鼠 | 手指拖曳 |
| 撈網 | 點滑鼠左鍵或空白鍵 | 點一下畫面（網子會移到手指位置再撈） |
| 道具 | 數字鍵 1、2、3 或點右下角按鈕 | 點右下角道具按鈕 |
| 暫停 | Esc 或 P | 點右上角暫停鈕 |

## 遊戲內容

- **關卡挑戰**：5 片海域、每區 6 關，共 30 關。海域依序是珊瑚礁淺灘、海藻森林、沉船遺跡、深海熱泉、極光冰海。達成目標就過關，剩下的時間越多星星越多（剩 40% 以上 ★★★、20% 以上 ★★）。
- **5 隻 Boss**（每區第 6 關），各有特殊招式：
  - 巨鉗蟹王：大鉗子發紅後夾擊，網子會被夾住。
  - 深淵大章魚：朝網子噴墨，遮住畫面。
  - 鐵甲鯊：閃紅光後朝網子衝撞。
  - 深淵鮟鱇：讓海底變暗，只剩網子和牠的燈籠看得見。
  - 冰晶海龍：把網子附近的海水結冰，網子變慢又難撈。
- **街機模式**：1 枚代幣玩 60 秒，限時內盡量多撈。大約第 24 秒該海域的 Boss 會現身，擊敗有大獎。撈到寶箱有機會延長時間。
- **加成**：一網撈 3 隻以上有「一網多魚」加成；連撈次數越多彩票加成越高（最高 ×2）。
- **特殊生物**：
  - 👑 黃金魚王：撈魚累積下方能量條，集滿就會出現。
  - 墨汁烏賊：撈到會爆炸，全場一般魚群全部入袋。
  - 電鰻：撈到放出連鎖閃電；撈失敗網子會觸電麻痺。
  - 沉沒寶箱：開出彩票、道具、代幣或延長時間。
  - 刺河豚：網子移動太快會脹氣，脹氣時很難撈。
- **海洋圖鑑**：27 種海洋生物，沒撈過的只顯示黑影。記錄捕獲次數和最重的一隻。
- **背景音樂與音效**：用程式即時合成，音樂和音效可以分開開關。

## 成長系統

- **彩票**：撈魚賺彩票，關卡和街機都能賺，失敗或中途離開也會帶回已賺到的彩票。
- **漁具商店**（用彩票購買）：
  - 網具升級（永久，各 5 級）：網框尺寸、收網速度、網目強度（提高捕獲率，3 級和 5 級時對 Boss 傷害 +1）。
  - 道具：誘魚餌（把附近的魚吸向網子）、冰凍珊瑚（全場減速）、墨汁炸彈（立刻全場爆彈），各最多持有 9 個。
  - 代幣兌換：250 彩票換 1 枚代幣。
- **代幣**：街機模式每局 1 枚。一開始有 5 枚；每天第一次開啟送 3 枚；關卡第一次拿到的每顆星換 1 枚。

## 存檔

## 技術說明

- 純 HTML5 Canvas 和 JavaScript，沒有用任何外部函式庫，也不需要圖片或音檔。
- 魚、Boss、場景全部用程式繪製；音樂和音效用 Web Audio 即時合成。
- 遊戲數值集中在程式開頭的資料表（`AREAS`、`SP`、`LEVELS`、`UPS`、`ITEMS`），調整難度時改這幾個地方即可。
